# EnvironmentSensor (Archived)

> **This repository is archived.** It was an early standalone ESP8266-based environmental sensor
> that connected directly to Adafruit.io via MQTT. It uses a different architecture from the
> SensorIoT system and is no longer actively developed.
>
> For the current environmental sensing system, see:
> - **[SensorIoT-GW](https://github.com/ChrisBrinton/SensorIoT-GW)** — Consolidated embedded firmware and hardware
> - **[SensorIoT-Broker](https://github.com/ChrisBrinton/SensorIoT-Broker)** — Consolidated backend services
> - **[SensorIoT_app](https://github.com/ChrisBrinton/SensorIoT_app)** — React Native mobile app
>
> This repository is kept for historical reference only.

## Original Description
ESP8266-based IoT environmental sensor with DHT22 (temperature/humidity) and Dallas 1-Wire (external temperature) sensors. Connects to Adafruit.io cloud platform via MQTT. Features a 128x32 OLED display for real-time readings.
